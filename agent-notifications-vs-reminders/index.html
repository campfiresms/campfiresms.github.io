Notification workflows

AI agent notifications vs scheduled reminders

Choose the service by the event that starts it, the response it needs, and what keeps running.

By Campfire SMS · Published October 7, 2026

An agent notification reports something that happened during work. A scheduled reminder delivers a message at a chosen future time. If the agent needs the content of your answer, look for a two-way reply path as well.

There are three separate jobs to consider

  • Deliver an event update: the build finishes or the agent encounters a question, then it sends a message.
  • Schedule a future nudge: a service stores the time and delivers the reminder later.
  • Carry a human answer back: the runtime retrieves the reply and uses it in the task.

A product may cover more than one job, but “supports agents” or “has MCP” alone does not tell you which ones. Inspect what the tools do and what your response can change.

Campfire SMS connects agent updates and human replies over SMS. Your agent remains responsible for observing the result and executing the work.

Is the trigger a result or a time?

“Text me when the build finishes” depends on observing the build. “Remind me at 9am tomorrow to inspect the result” depends on a clock and durable scheduling. The messages can concern the same task while requiring different infrastructure.

For a completion or blocker notification, instruct the connected agent to send an update when it has evidence of the event. For a future reminder that must survive today's session ending, choose a service that owns the schedule.

NudgeBell documents scheduled reminders with escalation and human acknowledgment, continuing on its servers after creation. See its agent reminder documentation and our NudgeBell vs Campfire SMS comparison.

Is the response acknowledgment or an instruction?

Acknowledgment answers “did you see this?” A task reply can answer “use ISO dates,” “focus on migration risk,” or “include the missing-data note.” An agent needs access to the content of that reply to act on it.

With Campfire SMS, the agent checks its SMS inbox, incorporates the message, and acknowledges the handled message IDs. That acknowledgment concerns processing the input. It is distinct from a human acknowledging a reminder.

Use the MCP SMS guide to see the send, check, and acknowledge tools. Native permissions and reviews remain in their existing interfaces.

What needs to remain available?

Ask which part of the workflow remains running.
WorkflowWhat must be available
Local agent event alertThe agent and its computer need to observe the result and send the update.
Local SMS follow-upThe connected runtime needs to retrieve and process the human reply.
Persistent scheduled reminderThe reminder service must retain and execute the schedule after creation.
Campfire SMS Grok Bot wakeAn active configured webhook routine starts cloud work on incoming SMS; the user's PC can be off.

A hosted messaging endpoint does not automatically host the coding session. Choose the runtime separately from the notification channel.

Choose a useful first workflow

Start with a build completion text if you want to leave a long run. Choose PR notifications if you want a review summary. Use SMS questions and answers if small clarifications regularly interrupt work.

If both delivery later and active conversation matter, combine the workflows: let a reminder service nudge you at the scheduled time and use Campfire SMS to talk about work in an available agent runtime.

Connect your agent, verify an actual text and reply, and give it a concrete rule for when to reach you.

Common questions

Is an agent notification the same as a scheduled reminder?

A notification usually follows an observed task event. A reminder follows a stored schedule. Check the trigger and the infrastructure that owns it.

Does acknowledgment send my instructions back to an agent?

An acknowledgment flag confirms that a notification was seen or a message was handled. Arbitrary instructions need a reply interface that returns their content to the agent.

Can I combine reminders and two-way agent SMS?

Yes. A reminder service can handle future nudges while Campfire SMS carries a conversation with an available agent. Each workflow keeps its own runtime requirements.
