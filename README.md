# Campfire SMS

Dependency-free GitHub Pages site for Campfire SMS, including the homepage, public SMS opt-in flow, privacy policy, and SMS terms.

## Guides

The static `guides/` section contains two workflow articles. Edit their HTML directly; no build step is required. Keep examples aligned with the product behavior, label illustrative exchanges, and update `sitemap.xml` when adding public pages. Each guide has its own title, description, canonical URL, social metadata, and Article structured data.

Preview locally with `python -m http.server 8000` and open `http://localhost:8000/`.
