CAMPFIRE’S LANE

Hosted, two-way SMS for concise agent handoffs.

Campfire is not a full mobile IDE or remote-control replacement. It is for getting the update, replying by text, and returning the instruction to the connected agent.

PICK THE RIGHT PAGER

Campfire is a fit when a concise reply is enough.

Choose hosted two-way SMS when

  • You want an alert in your ordinary SMS inbox, not another mobile app.
  • Your agent is already running and you need to answer a short question or give a bounded next instruction.
  • You want a hosted return path rather than wiring an outbound text tool and inbound routing yourself.
  • You need a practical pager for Codex, Claude Code, Grok, OpenCode, or another compatible coding agent.

Choose another option when

  • You need to inspect a full diff, terminal, file tree, or visual interface on your phone.
  • You need an agent or computer that is stopped to wake up from a text.
  • You need to complete a native runtime approval remotely.
  • Your team already lives in a chat platform and wants its richer, app-based conversation there.
