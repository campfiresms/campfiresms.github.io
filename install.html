Before running the command

For the local Codex or Grok Build connection, use Windows, macOS, or Linux with Node.js 18+ (including npx), Python 3.12+, and a working supported agent CLI. Keep the computer awake and online while the agent works. The local connector does not wake stopped sessions.

Setup time depends on downloads, installed runtimes, and SMS delivery. Complete the two-way test before leaving your desk.

  1. Verify your phone

    CampfireSMS sends a verification code and creates your free 40-message trial. No credit card is required. Choose and confirm a six-digit PIN for your account; later visits use your phone number and PIN.

  2. Run the command CampfireSMS gives you

    npx -y @campfiresms/setup XXXX-XXXX

    The command is temporary, single use, and expires after 10 minutes.

  3. You're connected

    The installer registers CampfireSMS with Codex, Grok Build, or both when installed and stores the permanent installation credential locally. Open or restart your agent, then ask: “Use CampfireSMS to keep me updated on this task.” You never need to copy or edit credentials, environment variables, or MCP configuration.

  4. Test both directions

    Send the test message, then reply TEST. CampfireSMS confirms when setup is complete.

Each installation is separate.

You can rename or revoke a computer from your CampfireSMS account. Revoking one installation does not expose or alter another.

What the installer does

It installs the client-only CampfireSMS MCP connector, registers it with each supported local agent it finds, validates the connection, and reports a clear result. It does not clone a repository or run another AI model.

Use your first connected session

Follow the SMS notifications walkthrough, or prepare a task with the away-from-desk guide.

Update or recover a connection

If an installation command has expired or was already used, sign in and create a new command for that computer. If your existing credential is valid, refresh the connector with:

npx -y @campfiresms/setup update

If your credential was revoked, expired, or is missing, create a new installation command instead. Restart your agent after updating, ask it to open a bridge, and test both directions. Check the account allowance if messages still do not arrive.

Revoke one computer

  1. Sign in using your verified phone and PIN.
  2. Under Add computers, find the installation by its label. Use Rename and Save name to make computers easy to recognize.
  3. Select Revoke for that installation. Its credential can no longer access the bridge; your other installations keep their own credentials.

The permanent credential is stored locally by the installer, not shown for copying in the account page. Phone verification proves control of a number, not permanent personal identity.

Remove the local connector

After revoking the installation, remove each local MCP entry you use:

codex mcp remove campfire
grok mcp remove campfire
