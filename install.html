ONE COMMAND

Connect CampfireSMS to Codex.

Phone number → verify → one local command → connected.

Start free demoLog in ↗

  1. Verify your phone

    CampfireSMS sends a verification code and creates your free 40-message demo. No credit card is required.

  2. Run the command CampfireSMS gives you

    npx -y @campfiresms/setup XXXX-XXXX

    The command is temporary, single use, and expires after 10 minutes.

  3. You're connected

    The installer registers CampfireSMS with Codex and stores the permanent installation credential locally. You never need to copy or edit credentials, environment variables, or Codex configuration.

  4. Test both directions

    Send the test message, then reply TEST. CampfireSMS confirms when setup is complete.

Each installation is separate.

You can rename or revoke a computer from your CampfireSMS account. Revoking one installation does not expose or alter another.

What the installer does

It installs the client-only CampfireSMS MCP connector, registers it with Codex, validates the connection, and reports a clear result. It does not clone a repository or run another AI model.

Remove CampfireSMS

Revoke the installation from your account, then remove the local Codex entry:

codex mcp remove campfire
