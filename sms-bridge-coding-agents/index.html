SMS bridge for coding agents

CampfireSMS gives an already-running coding agent a hosted way to reach you by text—and gives you a way to reply so the work can continue.

THE CORE JOB

Agent needs attention → you get a text → the task continues.

Campfire is purpose-built for the moment an agent finishes a step, reaches a blocker, or needs a bounded decision while you are away from your desk.

  1. 01

    Your agent sends an update

    Ask it to text when there is a result, a blocker, or a question worth your attention.

  2. 02

    You reply in your normal SMS app

    Give a short instruction, answer a question, or redirect the next step without opening a separate chat app.

  3. 03

    The connected agent checks the bridge

    It receives the reply in its existing environment and can continue within its existing tools and permissions.

A NARROW, USEFUL ROLE

A two-way bridge, not a phone-sized development environment.

Campfire keeps the actual coding session where it belongs: in the agent’s normal environment. SMS handles the handoff when the agent needs you.

More than push-only notifications

A push alert can tell you a task changed state. Campfire also gives you a return path for a concise reply the agent can check.

Not a mobile remote-control app

It is not a replacement for Claude Remote Control, a remote desktop, or a full mobile IDE. Campfire does not put your terminal, files, or approvals on your phone.

SMS instead of another chat surface

Telegram and Discord bridges use their own apps, accounts, and notifications. Campfire uses your ordinary SMS inbox for the short exchange.

More than an outbound SMS tool

An outbound-SMS MCP tool can send a message. Campfire supplies a hosted, verified two-way path so replies can reach the connected agent.
