THE CAMPFIRE RELAY

Message transport for an existing agent.

Campfire receives SMS, queues the message with its source and session context, and delivers it to the active agent through an authenticated bridge.

The agent keeps its tools, files, context, and authority. Campfire does not run another model or control the agent.
