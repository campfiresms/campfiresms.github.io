How it works

Using CampfireSMS with your coding agent.

1

Install CampfireSMS

Run the installer on the computer where you use Codex or Grok Build.

2

Give your agent a task

Tell the agent what to do and ask it to send updates through CampfireSMS.

3

Leave and continue by text

Receive updates, answer questions, or change the instructions from your phone.

SMS messages

What moves between your agent and your phone.

  • Status updates
  • Questions and approvals
  • Agent instructions
  • Long-running task monitoring

CampfireSMS carries short messages between your verified phone and an agent already running in Codex or Grok Build. It does not run another model, move your files, or replace native agent approvals.
