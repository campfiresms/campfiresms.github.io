What your connection needs

Grok Bot: Configure hosted MCP and an active webhook routine. Incoming texts can start the cloud routine while your PC is off. Grok Bot walkthrough.

Local agents: Keep your computer awake and online with the agent running and checking for replies. Setup needs Node.js 18+ and Python 3.12+. The connector does not wake a stopped session. Local-agent setup.

Your agent uses its existing tools and permissions. SMS replies can steer that work; native permission approvals stay in the agent.
