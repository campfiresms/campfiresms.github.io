ntfy vs Campfire SMS

Free, open-source push alerts compared with two-way texts between you and your agent.

By Campfire SMS · Published October 16, 2026

ntfy is a free, open-source push notification service. Anything that can send an HTTP request, such as a Claude Code hook, can push an alert to the ntfy app on your phone, and you can run your own server. It is built for alerts: getting an answer back to your agent is a part you build yourself. Campfire SMS lets the agent you already run text your phone number and read your reply, with no app and nothing to host. Pick ntfy for free alerts you wire up yourself. Pick Campfire SMS when the agent needs an answer from you.

What ntfy does

ntfy sends push notifications to your phone or desktop from a plain HTTP PUT or POST request. You pick a topic name, subscribe to it in the ntfy app, and anything that can make an HTTP request can publish to it. It is "100% free software," dual-licensed under Apache 2.0 and GPLv2, and you can run your own server. See ntfy.sh.

Without an account, the topic name is the only protection. ntfy's own docs say "the topic is essentially a password," so choose one that is hard to guess. Paid ntfy.sh plans let you reserve topic names.

Alerts vs answers

Most coding-agent pings fall into two groups.

  • Alerts tell you something happened: the build passed, the tests failed, the agent stopped. You read them and maybe walk back to your computer. ntfy is very good at this, and it is free.
  • Answers are what the agent needs from you before it can continue: "Use the staging database or a local copy?" Here the hard part is the return trip. Your reply has to reach the right agent session, and the agent has to pick it up.

ntfy's action buttons go part of the way. An http button sends a request to a URL you choose when you tap it, so you could add "Approve" and "Deny" buttons. You would host that endpoint, decide what each button means, and have the agent read the result. Campfire SMS does the return trip for you: you type an answer in plain words, and the agent retrieves it through the connector you installed.

The two can work side by side: ntfy for routine build alerts, and Campfire SMS for the questions that need you.

Choose ntfy if…

  • You mainly want alerts. You'll read them and respond at your computer.
  • You want it free, or you want to run the server yourself.
  • You're comfortable writing hooks or scripts and keeping them working.
  • You want alerts from more than your agent, such as servers, cron jobs, and home automation, in one app.

Choose Campfire SMS if…

  • You want the agent you already run (Codex, Claude Code, Cursor, Grok Bot, OpenCode, or Grok Build) to ask you a question and read your answer.
  • You don't want to write hooks, host an endpoint, or keep a topic name secret.
  • You'd rather get real texts in your normal inbox than install another app.
  • You use Grok Bot and want a text to start its cloud routine while your PC is off.

Setup is three steps: sign up at campfiresms.com, verify your phone (40 free texts, no card), and run the one-time install command from your account. Then send a test text and reply. See the setup guide for each agent.

What Campfire SMS does not do

Campfire SMS is not a general notification service. It doesn't take alerts from servers or scripts outside your connected agent, and you can't self-host it.

  • Local agents need a live session. Codex, Claude Code, Cursor, OpenCode, Grok Build, and other local agents need the computer awake and online and the session running. Campfire SMS does not wake a stopped local session. Grok Bot is the exception: an active webhook routine can start it in the cloud when you text.
  • Replies don't grant new permissions. A text can steer the task, but the agent keeps the permissions it already had. Native approvals stay in the agent's own interface.
  • SMS isn't end-to-end encrypted. Don't text secrets, and keep sensitive detail on the computer.

Common questions

Can ntfy notify me when Claude Code finishes?

Yes. ntfy accepts a plain HTTP request, so a Claude Code hook, for example on the Stop or Notification event, can post a message to your ntfy topic. You write and maintain the hook yourself.

Can I reply to my coding agent through ntfy?

Not as a chat reply. ntfy notifications can carry action buttons, and an http button sends a request to a URL you choose when tapped. You could build approve and deny buttons that way, but you host the endpoint and teach the agent to read it. Campfire SMS returns your text reply to the agent without that work.

Is ntfy free?

Yes. You can use the public ntfy.sh server without signing up, or run your own server. As of October 2026, paid ntfy.sh plans start with Supporter (2,500 daily messages), listed at $5 to $6 a month depending on billing, and add reserved topics and higher limits.

Is ntfy private?

Without an account, anyone who knows your topic name can read or post to it. ntfy says the topic is essentially a password, so pick one that is hard to guess, reserve it on a paid plan, or self-host.

Do I need an app for Campfire SMS?

No. Texts arrive in your phone's normal messages app, on an iPhone or an Android phone. ntfy needs its app or the web app to receive notifications.
