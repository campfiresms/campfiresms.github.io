About

Stay connected to the work.

CampfireSMS is an SMS bridge for coding agents. Get updates, answer questions, and send instructions from your phone.

A coding task can keep running after you step away from your desk. CampfireSMS gives that task a way to reach you through an ordinary text message, and gives you a way to reply.

What CampfireSMS does

You connect a verified phone number to your agent’s environment, start a task, and ask the agent to use CampfireSMS. The agent can text you when it finishes work, needs clarification, or hits a blocker. Your reply can provide an answer or change the task’s instructions.

The work stays in the agent’s own environment. CampfireSMS carries the conversation; your existing agent provides the model, tools, and access to your project. Your phone needs SMS service, but does not need a mobile data connection or a separate chat app to exchange texts.

Use the agent you already have

CampfireSMS can be used with Codex, Grok, Claude, OpenCode, and other agents that can use its MCP tools or HTTP API. Connection steps depend on the host. The installer can register the local connector with detected Codex and Grok Build installations; other compatible hosts need their own configuration.

Grok Bot can use the installed Campfire client with a native routine. Grok Build can host the connector over stdio MCP. The Grok guide explains both setups.

What keeps the connection working

The agent’s environment must remain available and online. With the local connector, the agent or a scheduled routine checks the bridge for replies. Installing the connector alone does not schedule those checks or wake an idle agent. Keep a local computer awake, or run the agent in an environment that stays available.

CampfireSMS does not run an additional AI model or replace your agent’s permissions. A reply can guide work within existing authority; native approval prompts still need to be handled in the agent’s environment.

Pricing and privacy

Start with free setup messages, then use a monthly plan, one-time message packs, or both. Purchased credits do not expire. See current prices and message counting for the full details.

SMS is not end-to-end encrypted. CampfireSMS and telecommunications providers process message content to deliver the conversation, so keep secrets and sensitive project details out of texts. You can revoke an installation from your account or reply STOP to opt out of SMS. Read the privacy policy and SMS terms.
