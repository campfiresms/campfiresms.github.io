Messaging comparison

Ways to hear from your AI coding agent on your phone

Six ways to get alerts, questions, and approvals from Claude Code, Codex, or Cursor while you're away from your desk.

By Campfire SMS · Published October 16, 2026

If your agent only needs to tell you something finished, a free push service like ntfy or a one-time purchase like Pushover is enough. If it needs an answer from you, pick something with a return path: Campfire SMS (texts to your own number, from several agents), /call-me (a call on your iPhone), or Claude Code's Telegram plugin (a chat bot, Claude Code only). Building it yourself on Twilio gives full control but leaves the reply routing to you.

How to choose

Three questions narrow it down quickly.

  1. Does the agent need an answer, or just to tell you something? For "done" and "failed" alerts, ntfy and Pushover are cheap and dependable. For "which option should I take?", you need a way back to the agent: Campfire SMS, /call-me, or Telegram.
  2. Which agents do you use? The Telegram plugin is Claude Code only. Campfire SMS covers Codex, Claude Code, Cursor, OpenCode, Grok Build, and Grok Bot. /call-me lists any MCP client.
  3. Which phone, and do you want another app? /call-me needs an iPhone. ntfy, Pushover, and Telegram need their apps. Campfire SMS and DIY Twilio use your normal text inbox on any iPhone or Android phone.

Whatever you pick, a local agent still needs its computer awake and its session running to act on your reply.

1. Campfire SMS: real texts you can answer

Your agent texts your own phone number, and you reply in plain words. The agent retrieves your reply through the connector you installed, so there's no app, bot, or webhook to run. It works with Codex, Claude Code, Cursor, OpenCode, and Grok Build on your computer, and with Grok Bot in Grok's cloud, where a text can start its routine while your PC is off. Replies steer the task; they don't answer the agent's native permission prompts.

Best for: answering the agent you already run from your normal texts, without building anything. See setup.

2. /call-me (CallMeMCP): your agent rings your iPhone

The /call-me app lets an agent ring your iPhone on the native call screen, read its question aloud, and send back your spoken answer as text. Agents can also send texts into the app. Its number isn't a real phone number; it exists only inside the app. It needs iOS 17 or later.

Best for: urgent decisions and hands-free answers on an iPhone. Compare /call-me and Campfire SMS.

3. Claude Code Telegram plugin: free chat and approvals

Claude Code's official Telegram channel plugin pushes your messages into a running session, and current versions relay tool-permission prompts with Allow and Deny buttons. It's free, but you create a bot, install Bun, start Claude Code with the channel turned on, and keep the session open. It's a research preview and works only with Claude Code.

Best for: Claude Code users who already use Telegram. Compare the Telegram plugin and Campfire SMS.

4. ntfy: free, open-source push alerts

A hook sends an HTTP request to your ntfy topic, and the alert appears in the ntfy app. It's free without sign-up, and you can self-host the server. There's no chat reply, though action buttons can call a URL you host.

Best for: free "it's done" alerts for people who like to wire things up. Compare ntfy and Campfire SMS.

5. Pushover: pay once, dependable alerts

A $4.99 one-time purchase per platform, with 10,000 free messages a month per account. A hook calls its API when the agent stops or needs attention. It's one-way: emergency alerts can be acknowledged, but you can't answer the agent.

Best for: dependable alerts with no subscription. Compare Pushover and Campfire SMS.

6. DIY Twilio SMS: full control

Sending a text through Twilio is one API call. Getting your reply back to the right agent session takes an inbound webhook, authentication, and routing that you build and keep running, plus a rented number and Twilio's usage rates.

Best for: people who already run Twilio and want to own every piece. Compare DIY Twilio and Campfire SMS.

What about Remote Control?

Claude Code's Remote Control isn't a notification service: it lets you drive a local Claude Code session from the Claude app or a browser. It's worth a look if you want the full session on your phone. See Claude Code Remote Control vs SMS.

Common questions

What's the easiest way to have Claude Code text me when it's done?

Campfire SMS: sign up, verify your phone, run one install command, and ask Claude Code to text you when the task finishes. If you only want a push alert and don't mind writing a hook, ntfy or Pushover also work.

Can I answer my coding agent from my phone?

Yes, with Campfire SMS (text reply), /call-me (spoken or typed reply on an iPhone), or Claude Code's Telegram plugin (chat reply). ntfy and Pushover deliver alerts; answering through them means building your own endpoint.

Can I approve Claude Code permission prompts from my phone?

Claude Code's official Telegram channel plugin can relay tool-use approvals in current versions, and Claude Code Remote Control lets you drive the session from the Claude app. Campfire SMS replies steer the task but don't answer native permission prompts.

Is there a free option?

ntfy and the Claude Code Telegram plugin are free, and ntfy can be self-hosted. Pushover is a $4.99 one-time purchase per platform after a 30-day trial. Campfire SMS includes 40 free messages to try it.

Do any of these work while my computer is off?

Not for a local agent. Every option here needs the agent's session running to act on your reply. Campfire SMS can start Grok Bot's cloud routine when you text, because Grok Bot runs in Grok's cloud.
